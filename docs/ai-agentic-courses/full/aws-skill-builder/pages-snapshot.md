## 1. Building Generative AI Applications Using Amazon Bedrock (Includes Labs)
- **Link:** https://skillbuilder.aws/learn/K5FK8EE82U/building-generative-ai-applications-using-amazon-bedrock-includes-labs/UX8DFX691K
- **Access:** Subscription ($29/mo hoặc $449/year) · **9 giờ** · **Advanced** · Updated 2026-03-06
- **Rating:** 4.5/5 (328 reviews: 211×5★, 93×4★, 18×3★, 4×2★, 2×1★)
- **Description:** Dành cho application developers build GenAI applications bằng Amazon Bedrock APIs hoặc AWS-LangChain integration. Bao gồm architecture patterns cho: generate/summarize text, RAG, question answering; build RAG app bằng **Bedrock Knowledge Bases**; **AI Assistants dùng knowledge bases + user-developed tools (Bedrock Agents)**; safeguards bằng **Bedrock Guardrails**. Có eLearning interactions, knowledge checks, labs.
- **Objectives (đầy đủ):**
  1. Identify components của generative AI application + options customize FM
  2. Describe Bedrock foundation models, inference parameters, key Bedrock APIs
  3. Describe architecture patterns để build GenAI applications
  4. Identify AWS offerings cho monitoring, securing, governing Bedrock apps
  5. Describe LangChain components: prompt templates, chains, retrievers, agents
  6. Apply LangChain components với Bedrock: text/code generation, summarization, RAG, Q&A
  7. Use Bedrock Knowledge Bases implement RAG best practices
  8. Use Bedrock Agents với Knowledge Bases + Guardrails cho agent applications
- **Services:** Amazon Bedrock, AWS Lambda, IAM
- **Audience:** GenAI application developers · **Prereqs:** Python intermediate–expert · AWS Technical Essentials · AWS Lambda Foundations · Amazon Bedrock Getting Started · Foundations of Prompt Engineering
