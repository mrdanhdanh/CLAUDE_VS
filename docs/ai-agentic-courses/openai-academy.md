## 1. Tổng quan

OpenAI Academy chia 4 track theo vai trò + chuỗi **Builder Bootcamp** live/on-demand cho technical builders (agents, Codex, evals, RAG, production best practices).

## 2. 4 Track chính

| Track | Đối tượng | Nội dung |
|-------|-----------|----------|
| **Apply AI at Work** | Knowledge workers | Core habits: prompting + review; practice workflows lặp lại được; directing work with agents |
| **Build with AI** | Builders | Dùng Codex xuyên suốt software development lifecycle; build với OpenAI API |
| **Lead AI Adoption** | Leaders | Biến 1 AI initiative thật thành roadmap + draft AI strategy |
| **Teach and learn with AI** | Education | Apply AI vào teaching, academic work, career preparation |

## 3. Builder Bootcamp series (cho dev — free)

**API Builder Bootcamp** — 5 live sessions:
1. API Foundations
2. Realtime
3. **Agents**
4. **RAG**
5. **Production & Optimization**

> Attend đủ 5 sessions → **certificate of completion** (không bắt buộc lấy).

**Codex Bootcamp** — 3 cấp cho technical builders/engineering teams:
- **101: Agentic coding** — fundamentals thực hành
- **201: Team workflows** — repeatable team workflows
- **301** — advanced automation

**Builder Bootcamp series** (live virtual): các session chuyên đề agents, Codex, evals, RAG, production best practices.

**On-demand replays có sẵn:** Builder Bootcamp: RAG · Builder Bootcamp: Realtime.
