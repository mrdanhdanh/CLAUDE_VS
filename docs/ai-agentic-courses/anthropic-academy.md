## 2. Chi tiết khóa MCP (fetch trực tiếp 2026-09-12)

**Introduction to Model Context Protocol** — FREE · **16 lectures · 1h video · 1 quiz · Certificate of completion**

**Learning objectives:**
- Hiểu MCP architecture + client-server communication model
- Build MCP server expose tools bằng Python SDK
- Implement MCP client kết nối ứng dụng với server
- Tạo resources (expose data) + prompts (pre-defined workflows)
- Test/debug server bằng MCP Inspector
- Chọn giữa tool / resource / prompt theo control patterns
- Handle resource cleanup + async communication

**Prereqs:** Python cơ bản · async/await · API concepts.
**Cấu trúc:** (1) MCP fundamentals & server development — 8 lessons; (2) MCP client implementation & advanced features — 8 lessons. Hands-on project: document management system dùng MCP.
