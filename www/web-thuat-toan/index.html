Bài 001

Kadane — Maximum Subarray

Tìm đoạn con liên tiếp có tổng lớn nhất — O(n) · DP/Greedy

O(n) · O(1) space

📋 Đề bài

Cho mảng số nguyên nums, tìm đoạn con liên tiếp có tổng lớn nhất. Đoạn con phải chứa ít nhất 1 phần tử.

Ví dụ minh họa
Input[-2, 1, -3, 4, -1, 2, 1, -5, 4]
Output6 → [4, -1, 2, 1]
Giải thíchĐoạn [4,-1,2,1] có tổng 6 là lớn nhất

📝 Pseudocode

cur = maxSum = nums[0]
for i = 1 → n-1:
  cur = max(nums[i], cur + nums[i])
  maxSum = max(maxSum, cur)
return maxSum

Nhập dãy số

700ms

Trực quan

Đang xét Best cur window Đã duyệt
cur: 0maxSum: 0i: 0

      Bài 003

      Search in Rotated Sorted Array

      Tìm kiếm nhị phân trên mảng xoay — O(log n)

      O(log n)

      📋 Đề bài

      Mảng đã sắp xếp tăng dần bị xoay tại pivot chưa biết. Tìm target — trả về index hoặc -1.

      Ví dụ
      Inputnums=[4,5,6,7,0,1,2], target=0
      Output4
      Giải thíchMảng xoay tại index 4, 0 ở vị trí 4

      📝 Pseudocode

      l=0, r=n-1
while l ≤ r:
  mid=(l+r)//2
  if nums[mid]==target: return mid
  if nums[l] ≤ nums[mid]: // left sorted
    if target in [l,mid): r=mid-1 else l=mid+1
  else: // right sorted
    if target in (mid,r]: l=mid+1 else r=mid-1

        Bài 004

        QuickSort — Partition Visualizer

        Sắp xếp chia để trị với Lomuto partition — O(n log n) avg

        O(n log n) avg · O(n²) worst

        📋 Đề bài

        Sắp xếp mảng bằng QuickSort. Chọn pivot cuối, partition Lomuto: đưa pivot về đúng vị trí, đệ quy 2 nửa.

        Ví dụ
        Input[8, 3, 5, 1, 9, 2]
        Output[1, 2, 3, 5, 8, 9]
        PivotChọn cuối → partition → đệ quy

        📝 Pseudocode — Lomuto

        partition(arr, lo, hi):
  pivot = arr[hi]; i = lo
  for j = lo → hi-1:
    if arr[j] ≤ pivot: swap(arr[i], arr[j]); i++
  swap(arr[i], arr[hi]); return i
quicksort(arr, lo, hi):
  if lo < hi: p=partition(...); quicksort(lo,p-1); quicksort(p+1,hi)

          Bài 005

          Bounds — First & Last Occurrence

          Tìm biên trái/phải của target trong mảng sorted có duplicate — O(log n)

          O(log n) × 2

          📋 Đề bài

          Mảng sorted có thể chứa duplicate. Tìm first và last index của target. Nếu không có → [-1,-1].

          Ví dụ
          Inputnums=[1,2,2,2,3,4], target=2
          Output[1, 3]
          Giải thích2 xuất hiện từ index 1 đến 3

          📝 Pseudocode

          lowerBound(target): // first ≥ target
  l=0,r=n; while l<r: mid=(l+r)//2
    if nums[mid] < target: l=mid+1 else r=mid
upperBound(target): // first > target
  l=0,r=n; while l<r: mid=(l+r)//2
    if nums[mid] ≤ target: l=mid+1 else r=mid
first = lowerBound(t); last = upperBound(t)-1

            Bài 006

            Container With Most Water

            Tìm 2 đường chứa nhiều nước nhất — O(n) Two Pointers

            O(n)

            📋 Đề bài

            Cho height[] là chiều cao các cột. Tìm 2 cột tạo container chứa nhiều nước nhất. Diện tích = min(h[l],h[r]) × (r-l).

            Ví dụ
            Input[1,8,6,2,5,4,8,3,7]
            Output49 → cột 1(8) và 8(7): min(8,7)×7=49
            Giải thíchTwo pointers: hẹp dần, bỏ cột thấp

            📝 Pseudocode

            l=0, r=n-1, best=0
while l < r:
  area = min(h[l],h[r]) * (r-l)
  best = max(best, area)
  if h[l] < h[r]: l++ else r--
return best

            Left Right Best Đang xét

              Bài 007

              Longest Substring Without Repeating

              Chuỗi con dài nhất không lặp ký tự — O(n) Sliding Window + HashSet

              O(n)

              📋 Đề bài

              Cho chuỗi s, tìm độ dài chuỗi con dài nhất không có ký tự lặp. Dùng sliding window + Set/Map.

              Ví dụ
              Input"abcabcbb"
              Output3 → "abc"
              Giải thíchCửa sổ [0,2]="abc" dài 3, gặp 'a' lặp → trượt left

              📝 Pseudocode

              set={}, l=0, best=0
for r in 0→n-1:
  while s[r] in set: set.remove(s[l]); l++
  set.add(s[r])
  best = max(best, r-l+1)
return best

                Bài 008

                Next Greater Element — Monotonic Stack

                Phần tử lớn hơn tiếp theo — O(n) Stack đơn điệu

                O(n)

                📋 Đề bài

                Cho mảng nums, với mỗi phần tử tìm phần tử lớn hơn đầu tiên bên phải. Không có → -1.

                Ví dụ
                Input[2, 1, 2, 4, 3]
                Output[4, 2, 4, -1, -1]
                Giải thích2→4, 1→2, 2→4, 4→-1, 3→-1

                📝 Pseudocode

                stack=[], ans=[-1]*n
for i in 0→n-1:
  while stack and nums[stack.top] < nums[i]:
    idx = stack.pop(); ans[idx]=nums[i]
  stack.push(i)
return ans

                  📋 Đề bài

                  Khác BFSBFS chỉ đếm bước, Dijkstra tính trọng số

                  📝 Pseudocode

                  dist[S]=0, pq=[(0,S)]
while pq not empty:
  u = pq.popMin()
  for v in neighbors(u):
    if dist[u]+w(v) < dist[v]:
      dist[v]=dist[u]+w(v); parent[v]=u; pq.push(v)
trace parent E→S

                    Bài 010

                    0/1 Knapsack — 2D DP

                    Chọn vật phẩm tối ưu trong ba lô — O(n·W) · 2D DP

                    O(n·W)

                    📋 Đề bài

                    Cho n vật phẩm (weight, value) và ba lô capacity W. Mỗi vật chỉ lấy 1 lần. Tìm tổng value lớn nhất.

                    Ví dụ
                    Inputw=[2,3,4,5], v=[3,4,5,6], W=5
                    Output7 → chọn vật 0+1 (w 2+3=5, v 3+4=7)
                    DPdp[i][w] = max(dp[i-1][w], dp[i-1][w-wi]+vi)

                    📝 Pseudocode

                    dp[0][w]=0
for i=1→n:
  for w=0→W:
    if wi > w: dp[i][w]=dp[i-1][w]
    else: dp[i][w]=max(dp[i-1][w], dp[i-1][w-wi]+vi)
trace back từ dp[n][W]
