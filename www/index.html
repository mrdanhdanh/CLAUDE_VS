Quy trình Harness 2.2

2 pipeline + gates + skills + 2.1/2.2 agentic — Process > Model · Bắt đầu từ Knowledge First

Bước 0 — Knowledge First (bắt buộc): đọc docs/knowleged.md + auto-learn suggest trước mọi task. Chạm pattern cũ → áp dụng Cách phòng tránh ngay.
Idea → Explore → Clarify → PRD → Design → Plan → Implement → Polish → Verify → Done

Mọi tác vụ đều phải đi qua đủ 8 bước. Với tác vụ nhỏ (1–2 tệp), quy trình được rút gọn nhưng không bỏ bước Polish.

  1. 1

    Explore — Khám phá

    Hiểu codebase + context: stack, file liên quan, pattern. Đọc README, package.json, registry.json + grep_search. Cần kiến thức sách → search_library top_k 5 qua MCP.

    • Input: Idea + workspace
    • Output: Tóm tắt stack + file chạm tới
    • Gate: ❌ không bỏ · mini: quick
    Tóm tắt stack Explore subagent
  2. 2

    Clarify — Làm rõ

    Mơ hồ → hỏi tối đa 3 câu có options, chốt giả định ghi vào PRD. Rõ → chốt assumption, rút gọn còn 1 câu.

    • Input: Idea + kết quả Explore
    • Output: Câu hỏi + giả định đã chốt
    • Gate: Rút gọn nếu rõ, không đoán bừa
    Câu hỏi + giả định vscode_askQuestions
  3. 3

    PRD — Đặc tả

    Vision, user stories P0/P1, Scope In/Out, Non-Goals, Metrics. Trang www/ phải có Persistence · F5 · Scope. YAGNI gate: liệt kê CẮT trước GIỮ.

    • Output: .agent/plans/<slug>/prd.md (mini 5 dòng cũng phải có)
    • Gate: ❌ không bỏ · Nguồn thư viện có citation nếu dùng sách
    .agent/plans/<slug>/prd.md Plan agent
  4. 4

    Design — Thiết kế

    Palette 3–5 màu, typography 1–2 font, spacing 4/8, wireframe 375/768/1280, states đầy đủ, animation 150–300ms, a11y ≥4.5:1. Native-first, không thêm dep nếu chưa chứng minh cần.

    • Output: .agent/plans/<slug>/design.md
    • Gate: ❌ không bỏ · Không hardcode hex/px lẻ
    .agent/plans/<slug>/design.md Designer agent
  5. 5

    Plan — Lập kế hoạch

    5–10 todos (3–7 từ/todo), File Changes, Risks, cách kiểm tra. Phức tạp → hỏi user confirm trước khi code.

    • Output: plan.md + manage_todo_list
    • Gate: ❌ không bỏ · 1 in-progress tại 1 thời điểm
    .agent/plans/<slug>/plan.md + todos Plan agent
  6. 6

    Implement — Thực thi

    Todo-driven + TDD gate (RED trước) + root cause trước + ladder 7 nấc (YAGNI → reuse → stdlib → native → dep đã cài → 1 dòng → tối thiểu). get_errors sau mỗi edit.

    • Output: Code tối thiểu chạy được
    • Gate: Không production code nếu chưa có test fail
    Mã nguồn Implement agent · get_errors
  7. 7

    Polish — Hoàn thiện

    Audit product-quality: responsive không vỡ, đủ states (hover/focus/active/disabled/loading + loading/empty/error/success), animation transform/opacity, contrast, keyboard, aria, locale-owned copy.

    • Gate: ❌ không bỏ · Xấu = chưa xong
    • Verify animation: đo --angle bằng Playwright, không nhìn mắt
    Chuẩn product-quality Polish agent
  8. 8

    Verify — Kiểm định

    build/test/lint + visual + bằng chứng Pages runtime (curl CORS + addEventListener + test F5). Fresh evidence, loop max 3 lần/check. FAIL → Implement, Blocked → báo human.

    • Gate: PASS mới Done · Không dùng kết quả cũ
    • Fresh-eyes: REQUIRED (UX) · RECOMMENDED (regression) · OPTIONAL (deterministic)
    PASS → Done Verify agent · loop fix

Rút gọn cho tác vụ nhỏ

Explore (nhanh) → Clarify (1 câu) → PRD mini (5 dòng) → Design mini → Plan (3 todos) → Implement → Polish → Verify. Không bỏ Polish — giao diện xấu = chưa xong.

Vòng lặp kiểm định

Verify FAIL → Implement sửa → Polish lại → Verify lại (max 3 lần/check). Blocked → báo human. Chỉ PASS + fresh evidence mới Done.

Todo-driven + trace

5–10 todos, 1 in-progress tại 1 thời điểm, get_errors sau mỗi edit. PRD/Design/Plan lưu tại .agent/plans/<slug>/ để trace.

Anti-patterns (CẤM)

Code ngay không PRD/Design · Bỏ Polish · Không todo · In code chờ copy · Đoán thay vì hỏi · Pin model: · Sửa status.json tay · Verify animation bằng mắt.

Bounded repair loop — không phải /harness thu nhỏ: không tạo PRD/Design dài, chỉ 3–5 todos, tập trung root cause + Learn. Confidence < MEDIUM → không close.
Knowledge → Reproduce → Root Cause → Fix → Verify → Learn → Done

Không dùng /harness cho bug — sẽ tạo PRD/Design thừa. Không bỏ Reproduce và Learn — fix xong không ghi knowledge = chưa xong.

  1. 0

    Read Knowledge — Đọc bài học cũ

    Đọc docs/knowleged.md + auto-learn suggest. Chạm pattern cũ → áp dụng Cách phòng tránh ngay.

    • Gate: ❌ không bỏ · Knowledge Gate
    • Output: Đã đọc + KN liên quan
    knowleged.mdauto-learn suggest
  2. 1

    Reproduce — Tái hiện có bằng chứng

    Steps + Expected/Actual + evidence (log, ảnh, file:line). Bug nhỏ dùng grep/read trực tiếp, bug rộng mới delegate Explore.

    • Gate: FAIL → ask/stop, không đoán fix
    • Output: Repro steps + evidence
    Reproduce Gatesystematic-debugging p1
  3. 2

    Root Cause — file:line + 5 Whys

    Single hypothesis, evidence first. Uncertain → investigate thêm / escalate, không fix bừa.

    • Gate: uncertain → investigate/escalate
    • Output: Root cause + file:line
    Root Cause Gate5 Whys
  4. 3

    Fix — Sửa ở gốc, bounded

    Minimal fix + scope control + TDD (RED trước) + ladder. get_errors affected files. Chỉ audit Polish nhanh nếu bug là UI.

    • Gate: Minimal Fix · Confidence HIGH/MEDIUM/LOW (LOW → STOP)
    • Output: Code + get_errors pass
    tdd-gateminimal-ladder
  5. 4

    Verify — Không regression

    Re-test + edge + regression + build/lint full scope. Fresh evidence, không dùng kết quả cũ.

    • Gate: Verification Gate · Fresh-eyes tiered
    • Output: PASS full scope
    PASS → LearnVerify agent
  6. 5

    Learn — Biến bug thành knowledge

    Lưu .agent/bugs/<slug>/bug.md + thêm KN-XXX vào docs/knowleged.md (bảng + chi tiết + anti-pattern).

    • Gate: ❌ không bỏ · Learning Gate
    • Output: bug.md + KN mới
    auto-learn proposelearn agent
  7. 6

    Done — Đóng vòng

    Tóm tắt + KN + files changed. Confidence ≥ MEDIUM mới close.

    DONEreport
