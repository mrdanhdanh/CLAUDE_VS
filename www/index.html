Quy trình Harness v2

8 bước từ ý tưởng đến sản phẩm hoàn chỉnh — Process > Model

Idea → Explore → Clarify → PRD → Design → Plan → Implement → Polish → Verify → Done

Mọi tác vụ đều phải đi qua đủ 8 bước. Với tác vụ nhỏ (1–2 tệp), quy trình được rút gọn nhưng không bỏ bước Polish.

  1. 1

    Explore — Khám phá

    Hiểu codebase, đọc README, package.json, tìm pattern liên quan bằng grep.

    Tóm tắt stack Explore subagent
  2. 2

    Clarify — Làm rõ

    Nếu ý tưởng còn mơ hồ, hỏi tối đa 3 câu có lựa chọn và chốt giả định.

    Câu hỏi + giả định vscode_askQuestions
  3. 3

    PRD — Đặc tả

    Biến ý tưởng thành đặc tả: tầm nhìn, user stories P0/P1, phạm vi, tiêu chí thành công.

    .agent/plans/<slug>/prd.md Plan agent
  4. 4

    Design — Thiết kế

    Định nghĩa hệ thống thiết kế: bảng màu, typography, wireframe 375/768/1280, trạng thái.

    .agent/plans/<slug>/design.md Designer agent
  5. 5

    Plan — Lập kế hoạch

    Chia nhỏ công việc thành todos, liệt kê tệp thay đổi, rủi ro và cách kiểm tra.

    .agent/plans/<slug>/plan.md + todos Plan agent
  6. 6

    Implement — Thực thi

    Làm theo từng todo, mỗi lần chỉ một todo ở trạng thái đang làm, kiểm tra lỗi sau mỗi lần sửa.

    Mã nguồn Implement agent · get_errors
  7. 7

    Polish — Hoàn thiện

    Rà soát giao diện: responsive, trạng thái, animation 150–300ms, accessibility.

    Chuẩn product-quality Polish agent
  8. 8

    Verify — Kiểm định

    Chạy build/test/lint, kiểm tra trực quan, lặp lại sửa lỗi tối đa 3 lần cho đến khi đạt.

    PASS → Done Verify agent · loop fix

Rút gọn cho tác vụ nhỏ

Explore (nhanh) → Clarify (1 câu) → PRD mini → Design mini → Plan (3 todos) → Implement → Polish → Verify. Không bỏ Polish.

Vòng lặp kiểm định

Nếu Verify chưa đạt → quay lại Implement để sửa → Polish lại → Verify lại. Chỉ khi PASS mới hoàn tất.

Triết lý: Process > Model — Chất lượng đến từ quy trình, không phụ thuộc mô hình.
