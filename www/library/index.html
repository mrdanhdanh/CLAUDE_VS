🤖 Cho AI đọc — 2 cách

A. Trong browser (mọi AI)

// Trong console hoặc AI webview
await window.LibrarySearch.search("điều khoản thanh toán", {top_k:5})
// → [{bookName, chunkId, text, snippet, score, page}]

window.LibrarySearch.listBooks()
window.LibrarySearch.getStatus()

B. MCP cho VS Code / Claude Code

// .vscode/mcp.json
{
  "servers": {
    "library": {
      "command": "node",
      "args": ["./www/library/mcp-server.mjs"]
    }
  }
}
// Tools: search_library, list_books, get_book
// Đọc www/library/export.json (bấm Xuất để tạo)
