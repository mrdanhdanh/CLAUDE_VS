🔗 Sync Code — Đồng bộ không cần DB

Tạo mã 6 ký tự, chia sẻ cho máy khác — nhập cùng mã là thấy cùng list. Không cần tài khoản, không cần DB, lưu trên kvdb.io free.

Cách dùng: Bấm Tạo mã → Kết nối → tasks hiện tại sẽ được đẩy lên. Mở máy khác, bấm 🔗 Sync Code → nhập cùng mã → Kéo về là thấy.

Tuỳ chọn DB nhỏ free: nếu muốn DB thật, dùng Supabase (500MB free) tạo 1 bảng todos với cột workspace_id = mã này, hoặc Firebase Firestore — chỉ cần dán anon key, không cần backend.
