## 2. Wireframe

### Pipeline
```
RAG hits ──► quarantine (validate, redact secret) ──► compress (score sort + truncate ≤max) ──► isolate (per subtask bounded) ──► inspect (counts/ids/hashes)
scratchpad: file/runtime object cho session hiện tại (.agent/memory/scratchpad.md)
```

### Failures & Fix (Lesson 12)
- Poisoning → quarantine (validate + redact)
- Distraction → compress (summarize/trim)
- Confusion → isolate (per subtask)
- Clash → versioning (ghi ts + source)
