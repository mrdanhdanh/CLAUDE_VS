## 1. Vision
- **One-liner:** Quản lý context động — scratchpad + compress + isolate per subtask + chống poisoning — cho RAG và harness.
- **Problem:** Context quá lớn → distraction; hallucination lọt vào → poisoning; instructions mâu thuẫn → confusion.
- **Target User:** Explore/Plan agents, RAG consumers.

## 4. Success Metrics
- **Metric 1:** `compress` 5 hits (~3000 chars) → ≤2000 chars, giữ top scores
- **Metric 2:** `isolate` 2 subtasks → 2 summaries riêng, không lẫn
- **Metric 3:** `quarantine` text chứa `sk-...` → reject + redact
- **Metric 4:** `get_errors` pass

## 5. Edge Cases & Constraints
- **Empty hits:** compress trả `[]`, không crash
- **Constraint:** Node 18+, 0 deps
- **Secret:** inspect chỉ counts/hashes, không raw prompt

## 6. Assumptions
- Heuristic trim (giữ top-score) đủ cho v1, LLM summarize để P1
