## 2. Wireframe

### MCP Hardening
```
catalog.json (+library vendor 1.1.0) ──► mcp-check.mjs --tool search_library ──► permitted (holds vendor)
mcp-server.mjs (version 1.1.0) ──► tools/list ──► version pin
tools/call ──► validate (P0-2) ──► execute ──► redact output ──► return
```

### A2A Card Validation
```
agents.yaml (3 built-in) ──► agent-card.mjs --file ──► validate each (name, type, endpoint/version) ──► report
```

### Library Vendor Entry

```json
{
  "id": "library",

}
```

### Output Redaction
```js
function redactOutput(text) {
  return String(text)
    .replace(/sk-[a-zA-Z0-9]{10,}/g, '***')
    .replace(/cpk-[a-zA-Z0-9]{10,}/g, '***');
}
// Apply to hit text/snippet before return
```
