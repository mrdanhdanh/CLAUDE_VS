## Addendum 2026-09-30 — MCP split theo lifetime (KN-086)

**Nguồn:** Uno Platform, .NET Blog 26/08/2026 ([devblogs.microsoft.com/dotnet](https://devblogs.microsoft.com/dotnet/how-uno-platform-uses-dotnet-mcp-ai-to-build-high-quality-apps/)).

**Nguyên tắc chọn khi tách MCP server:** split theo **lifetime**, không theo feature —
- **Docs/grounding (stateless, versioned):** server đọc tài liệu theo version; "sửa 1 trang doc là mọi agent nhận correction ngay lần gọi kế tiếp" → không bao giờ phục vụ tri thức stale.
- **App/runtime control (stateful, per-session):** stdio server sống theo phiên — chạy app (hot reload), xem (screenshot + XML visual tree: "pixels để phát hiện, structure để chẩn đoán"), hành động.

**Áp cho harness:** khi mở rộng MCP (ngoài `www/library/mcp-server.mjs` hiện có) — tài liệu/grounding tách khỏi runtime control; mỗi server 1 vòng đời. Luận điểm kèm: *"generation rẻ, verification không"* — ưu tiên khả năng kiểm chứng (docs versioned tươi + visual tree) hơn sinh thêm.
