# PRD: OpenBot Governance Phase 2 — AG-UI + MCP + Components + Routines

## 1. Vision
- **One-liner:** Nâng Harness v2 lên platform nhẹ — bring your own agent (AG-UI), governed MCP, component gallery, routines — vẫn 0 cài ngoài, chỉ nâng cấp bản thân.
- **Problem:** Phase 1 đã có audit/policy/credentials nhưng chưa có: (1) cách gắn agent ngoài (LangGraph/Mastra) vào Harness, (2) MCP catalog có grant per-agent, (3) Bot trả component thay vì chỉ text, (4) schedule task.
- **Target User:** Dev muốn gắn agent riêng, quản lý MCP có kiểm soát, cho Bot trả UI component, và schedule routine.

## 4. Success Metrics
- `node .agent/scripts/agent-registry.mjs list` → liệt kê agents từ `agents.yaml`
- `node .agent/scripts/mcp-check.mjs --tool google-drive --agent general` → ALLOW/DENY theo grants
- `node .agent/scripts/component-check.mjs --component hello --agent general` → published/withheld check
- `node .agent/scripts/routine.mjs add --cron "0 9 * * *" --prompt "check status"` → thêm routine, floor 15m, cap 20
- `node .github/harness/scripts/generate-status.mjs` → `www/status.json` có `platform: {agents, mcp, components, routines}` và `www/index.html` render được
- `get_errors` pass, `JSON.parse` valid, responsive 375/768/1280 không vỡ

## 5. Edge Cases
- `agents.yaml` chưa có → tạo mẫu 3 agents (general, knowledge, risk)
- `catalog.json` chưa có → tạo mẫu 2 MCP (google-drive, notion)
- `routines.json` quá 20 → refuse add, báo cap
- Cron <15m → refuse, báo floor
- Component chưa published → refuse, báo withheld
