## 4. Risks

| Risk | Mitigation |
|------|------------|
| Camera/Mic permission denied | Try/catch, show error + guide, not crash |
| getDisplayMedia not supported | Check `in` + fallback message |
| File too large | Check size >50MB → warn, not read |
| IndexedDB blocked | Try/catch, fallback message |
| Fetch CORS | Show error, not fake success |
| WebSocket invalid URL | Validate, show error state |
| Media tracks leak | Stop tracks on unmount/pause |
