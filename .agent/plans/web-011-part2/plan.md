# Plan: WEB 011 Part 2 — TEXT UNIVERSE

> Phased plan cho Text Universe. Kế thừa Core Runtime Part 1, không sửa core.

## 1. Architecture
- **Stack:** Vanilla JS + CSS (kế thừa base/layout/windows/modules.css)
- **Pattern:** Mỗi module là ES module lazy-load (`js/modules/<id>/index.js` + `manifest`), mount vào window body
- **State:** localStorage per-module + Core state (module status)
- **No deps:** Không thêm lib, tự parse markdown, tự diff LCS

## 4. Risks

| Risk | Mitigation |
|------|------------|
| Markdown XSS | Escape HTML trước khi parse, không dùng innerHTML với raw input |
| Code Playground infinite loop | Chỉ Run manual, không auto-run mặc định; iframe sandbox |
| Diff O(n*m) chậm với input lớn | Giới hạn 500 lines, debounce, không virtual |
| CSS conflict | Prefix class `.md-`, `.cp-`, `.diff-` |
| Persist race | Debounce 400ms, try/catch localStorage |
