## Architecture
- **Audit:** `.agent/audit.jsonl` + `.agent/scripts/audit.mjs` (log/tail/stats). Append-only, redacted, `requestId` = 6-char hex.
- **Policy:** `.agent/policy.json` + `.agent/scripts/policy-check.mjs` (check tool+target → ALLOW/DENY). Evaluator: `new Function` with 4 vars, 50ms timeout, deny first, fail-closed.
- **Credentials:** `.agent/credentials.enc.json` + `.agent/scripts/credentials.mjs` (set/get/list). AES-256-GCM, key from `HARNESS_CRED_KEY` or `~/.harness/key` (auto-gen), never logged.
- **Status:** `generate-status.mjs` reads audit/policy/credentials → adds `governance` to `status.json`.
- **UI:** `www/index.html` + `www/app.js` + `www/styles.css` render governance (3 cards + tail).
- **Enforce:** `.github/instructions/agent-governance.instructions.md` (applyTo `**`).
