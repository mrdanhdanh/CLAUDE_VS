# PRD: OpenBot Governance Upgrade — Harness v2 (Phase 1)

## 1. Vision
- **One-liner:** Nâng cấp Harness v2 với governance nhẹ học từ OpenBot — audit + policy + credentials — không cài gì ngoài, chỉ nâng cấp bản thân.
- **Problem:** Harness hiện chưa có audit trail runtime, chưa có policy gate trước khi act (shell/file/MCP), credentials để plain trong `.env` — khó truy vết, khó chặn hành động rủi ro.
- **Target User:** Dev dùng Harness/YUNIE trong VS Code Copilot Chat; YUNIE vận hành `www/status.json` và registry.

## 3. Scope

### In Scope (P0 — Phase 1, 0 deps)
- [x] Audit trail: `.agent/audit.jsonl` (append-only, JSONL, 1 dòng = 1 event: `ts, actor, tool, target, decision, rule, durationMs, error`)
- [x] Policy: `.agent/policy.json` (CEL-lite: `deny[]` trước `allow[]`, `fail-closed`, match `tool.name, intent, target, actor`) + script `policy-check.mjs` (Node 18+, no deps)
- [x] Credentials store: `.agent/credentials.enc.json` (AES-256-GCM, key từ `HARNESS_CRED_KEY` env hoặc `os keychain` fallback, never logged) + helper `credentials.mjs`
- [x] Instruction: `.github/instructions/agent-governance.instructions.md` (applyTo `**`, enforce audit/policy/credentials)
- [x] `www/status.json` + `www/index.html` hiện governance (audit count, policy status, credential status) — regenerate từ `generate-status.mjs`

## 4. Success Metrics
- `node .agent/scripts/policy-check.mjs --tool shell --target "rm -rf /"` → `DENY` + rule name, exit 1
- `node .agent/scripts/audit.mjs log --tool read --target "www/status.json" --decision permitted` → append 1 dòng vào `.agent/audit.jsonl`
- `node .agent/scripts/credentials.mjs set OPENAI_API_KEY --value "sk-..."` → ghi `.agent/credentials.enc.json` (không lộ value trong audit/status)
- `node .github/harness/scripts/generate-status.mjs` → `www/status.json` có `governance: { audit, policy, credentials }` và `www/index.html` render được
- `get_errors` pass, `JSON.parse` valid, responsive 375/768/1280 không vỡ

## 5. Edge Cases
- `.agent/audit.jsonl` chưa tồn tại → tự tạo, `generate-status` đếm 0
- `policy.json` malformed → `fail-closed` (deny all, log error, exit 1) — như OpenBot
- `HARNESS_CRED_KEY` chưa set → fallback `~/.harness/key` hoặc warn, không crash
- Audit log quá lớn (>10k dòng) → `generate-status` chỉ đếm + tail 100, không đọc hết vào RAM
- Policy chặn nhầm → dev sửa `policy.json` allow, audit ghi `refused` + rule để debug

## 6. Assumptions
- Node 18+ sẵn (đã dùng cho `harness-manager`, `generate-status`, `auto-learn`)
- Không thêm dep npm — chỉ `node:crypto`, `node:fs`
- `registry.json` vẫn là source of truth cho skills/instructions/agents/prompts/hooks — governance là layer bên cạnh, không thay registry
- `www/` vẫn là root GitHub Pages, workflow `pages.yml` không đổi
