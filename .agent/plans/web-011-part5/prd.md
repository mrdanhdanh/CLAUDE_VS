## 5. Edge Cases & Constraints
- EC1: Worker not supported → fallback to main thread, show message
- EC2: Geolocation permission denied → error + guide, not crash
- EC3: Web Audio not supported → fallback message
- EC4: SW not supported → show not supported, not fake
- EC5: Offline → fetch fails gracefully, show offline state
- Constraint: Vanilla JS, capability detection, no fake data, cleanup workers/audio on unmount
