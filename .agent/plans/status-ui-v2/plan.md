## Risks & Mitigations
| Risk | Mitigation |
|------|------------|
| Modal focus trap lỗi khi Tab | Test Tab/Shift+Tab loop, giữ focus trong modal, restore focus khi đóng |
| Wording mới làm lệch layout (dài hơn) | Dùng line-clamp, word-break, test 375px, không fixed width |
| SVG icons không đồng bộ stroke | Dùng 1 bộ Lucide 16-20px stroke 1.8, viewBox 24 |
| status.json fetch fail file:// | Giữ error card với hướng dẫn npx serve www, test JSON.parse |
| CSS variables hardcode sót | Grep hex sau khi edit, chỉ dùng var() |
| Reduced-motion bỏ sót | Thêm @media prefers-reduced-motion ở cuối, tắt animation/transition |
