## 1. Vision
- **One-liner:** Workflow graph có explicit control flow (sequential/branching/approval) + durable checkpoints (pause/resume) — như MAF `WorkflowBuilder`, nhưng file-based 0 deps.
- **Problem:** Harness pipeline hiện cứng 8 phase tuần tự, không branch theo điều kiện, không pause/resume, không approval node giữa chừng.
- **Target User:** Harness pipeline phức tạp (cần approval, cần branch UI vs non-UI, cần resume sau fail).

## 3. Scope

### In Scope (P0 — phải có)
- [ ] `.github/harness/scripts/workflow.mjs` — **MỚI**: `run`, `resume`, `status`, `list`; workflow definitions `harness-8phase` + `fixbug-7phase`; checkpoints `.agent/runs/<runId>.json`
- [ ] Workflow definition: nodes (phase + agent + command) + edges (sequential + conditional `when`) + approval nodes
- [ ] Checkpoint sau mỗi node (durable JSON), resume từ node cuối
- [ ] Tích hợp `handoff.mjs` (check rule trước khi chuyển node) + `trace.mjs` (1 trace/run, 1 span/node) + `audit.mjs` (log node transitions)
- [ ] Tests: run sequential, branch skip polish, approval block/resume, resume sau fail

### Nice to Have (P1)
- [ ] Concurrent nodes, magnetic manager, group-chat node
- [ ] `WorkflowBuilder` JS API (hiện chỉ CLI + JSON definition)

### Non-Goals
- MAF SDK Python / Foundry service (chỉ port pattern sang file-based JS), LLM executor (nodes chỉ log + checkpoint v1, chưa thực thi agent thật)

## 4. Success Metrics
- **Metric 1:** `workflow.mjs run --workflow harness-8phase --input '{"task":"demo","ui_changed":false}'` → skip polish, 7 nodes done
- **Metric 2:** `run` với approval node + không `--auto-approve` → pause `awaiting_approval`, `resume --approve` → tiếp tục
- **Metric 3:** Kill giữa chừng → `resume` tiếp tục từ checkpoint, không chạy lại nodes done
- **Metric 4:** `get_errors` pass, pipeline cũ không vỡ

## 5. Edge Cases & Constraints
- **Unknown workflow:** fail rõ ràng + `--list` gợi ý
- **Resume done run:** báo `already done`, không chạy lại
- **Constraint:** Node 18+, 0 deps, checkpoints gitignore (`.agent/runs/`)
- **Persistence:** Checkpoints ephemeral local (F5 mất nếu xóa file — nhưng file local nên F5 giữ), scope per-run

## 6. Assumptions
- Nodes v1 chỉ simulate (log + checkpoint + handoff check), chưa gọi agent thật — đủ để validate control flow
- Approval via CLI flag (không cần UI v1)
