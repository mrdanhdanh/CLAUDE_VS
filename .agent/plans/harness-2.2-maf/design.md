## 2. Wireframe

### Workflow Definitions
```js
WORKFLOWS = {
  "harness-8phase": {
    nodes: [
      {id: "explore", agent: "explore"},
      {id: "clarify", agent: "plan"},
      {id: "prd", agent: "plan"},
      {id: "design", agent: "design"},

      {id: "plan", agent: "plan"},
```

### Run Flow
```
run --workflow harness-8phase --input '{"task":"demo","ui_changed":false}' [--auto-approve]
  ├─► runId, trace start, checkpoint init
  ├─► for each node:
  │     ├─► if node.when && !evalWhen → skip (log skipped)
  │     ├─► if node.type === approval && !autoApprove → pause awaiting_approval, save checkpoint, exit 0 (paused)
  │     ├─► handoff check (prevAgent → agent) — warn nếu refused, không block v1
  │     ├─► trace span + audit log (best-effort, không block nếu fail)
  │     └─► mark done, save checkpoint
  └─► trace end, report done/skipped
resume --run <id> [--approve] → load checkpoint → tiếp tục từ node chưa done
```

### Checkpoint Schema
```json
{
  "runId": "abc123", "workflow": "harness-8phase", "task": "demo",
  "input": {"task": "demo", "ui_changed": false},
  "status": "running|paused|done",
  "nodes": [{"id": "explore", "status": "done|skipped|pending", "at": "..."}],
  "traceId": "...", "createdAt": "...", "updatedAt": "..."
}
```

### `when` Evaluator (minimal, an toàn)
- Chỉ support `input.<key> === true|false|"str"|123` + `&&`/`||`/`!` — không `eval` tự do.
- Parse đơn giản: thay `input.x` bằng JSON value rồi đánh giá biểu thức boolean an toàn.
