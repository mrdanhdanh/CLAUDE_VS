## 2. Architecture

```
www/design-showcase/
  index.html   — header reuse + hero + STATUS bar + filter + grid + modal + footer + toast
  styles.css   — reuse ../styles.css tokens + showcase-specific (grid/card/modal/filter/skeleton)

```

- **Data flow:** `designs.json` (static, copy) → app.js fetch → in-memory array → filter/search/sort → render grid. `../status.json` fetch riêng cho STATUS bar (fail → graceful "—").
- **Category map:** reuse CATEGORY_MAP từ search.mjs (10 cats) — hardcode trong app.js để không fetch thêm.
- **No framework:** vanilla HTML/CSS/JS, CSS variables, Inter + Plus Jakarta Sans + JetBrains Mono.
