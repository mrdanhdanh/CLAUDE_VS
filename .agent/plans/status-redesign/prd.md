# PRD: STATUS Redesign — Gọn, dễ xem, dễ tương tác

## 1. Vision
- **One-liner:** Làm lại trang STATUS cho gọn, dễ scan, dễ bấm — giảm rối, tăng tương tác.
- **Problem:** Trang hiện tại dài, nhiều section lặp (Hero + YUNIE + Quick Pages + Stats + Registry + Governance + Platform + Presets/Plans + Health/Pages + How-to) — user phải scroll nhiều, khó tìm nhanh, tương tác chưa rõ.
- **Target User:** Dev mở STATUS để check nhanh hệ thống, tìm registry, xem governance/platform, mở demo.

## 3. Scope

### In Scope (P0)
- [x] Rút gọn Hero (1 card thay vì 2 cột + 3 mini-cards)
- [x] Stats giữ 5 cols nhưng gọn hơn (icon + number + label, bỏ progress nếu rối)
- [x] Registry: sticky search + filter pills + table/cards, thêm jump anchor
- [x] Governance + Platform: gộp thành tabs (Governance | Platform) hoặc accordion, mỗi tab 3-4 cards + tail
- [x] Quick Pages: grid 4 cols desktop, 2 cols mobile, icon + title gọn
- [x] YUNIE: thu gọn thành 1 hero nhỏ + 5 letters grid, bỏ alias/intros dài (đưa vào modal hoặc collapsible)
- [x] Health + Pages: giữ nhưng gọn, bỏ How-to dài (đưa vào details)
- [x] Tương tác: search `/` focus, filter pills, copy buttons, playground link rõ

### Nice to Have (P1)
- [ ] Sticky nav (anchor links: Overview | Registry | Governance | Platform | Demos)
- [ ] Collapsible sections (details/summary) cho YUNIE/How-to

### Non-Goals
- Không đổi `status.json` shape — chỉ redesign `index.html` + `styles.css` + `app.js`
- Không thêm lib, không đổi `generate-status.mjs`
- Không đổi palette/typography — giữ design system hiện tại

## 4. Success Metrics
- Scroll từ top đến Health < 3 lần scroll desktop, < 5 lần mobile
- Tìm registry item < 2s (search + filter)
- Mở demo < 1 click từ Quick Pages
- `get_errors` pass, `JSON.parse` valid, responsive 375/768/1280 không vỡ, a11y AA

## 5. Edge Cases
- `status.json` fail → error card rõ, có Retry + link
- Registry empty → empty state + hint
- Governance/platform chưa có data → empty + CLI hint
- Mobile 375px: table → cards, filter pills wrap, hero 1 col

## 6. Assumptions
- Giữ `www/styles.css` v2.1 (glass + rainbow) — chỉ thêm layout gọn, không đổi token
- Giữ `www/app.js` logic — chỉ thêm tabs/accordion + sticky nav
- User đã quen STATUS cũ — redesign phải giữ anchor ids để link cũ không gãy
