# PRD: Todo Manager — Bài 010

## 1. Vision
- **One-liner:** Todo Manager — ứng dụng quản lý công việc nâng cao với state duy nhất, CRUD đầy đủ, filter/sort, dashboard và undo delete, lưu LocalStorage.
- **Problem:** Người học cần chuyển từ tương tác đơn lẻ sang ứng dụng có kiến trúc state, nhiều trạng thái và dữ liệu bền vững.
- **Target User:** Học viên JS (001-009 đã xong), dev muốn mẫu Todo architecture chuẩn.

## 3. Scope

### In Scope (P0 — phải có)
- [ ] State duy nhất: `{ tasks, filters: {search,status,priority,tag,overdueOnly}, sortBy }`
- [ ] CRUD: addTask, updateTask, deleteTask (không thao tác DOM trực tiếp sửa data)
- [ ] filterTasks, sortTasks, renderTasks, renderDashboard, saveData, loadData (tách hàm riêng)
- [ ] Dashboard 5 số: tổng, chưa hoàn thành (todo), đang thực hiện (doing), đã hoàn thành (done), quá hạn
- [ ] Form thêm/sửa: title*, description, priority, status, dueDate, tags (comma separated)
- [ ] List dạng card grid với nút Sửa/Xóa/Đổi trạng thái
- [ ] Search + filter: search title, status, priority, tag, overdueOnly
- [ ] Sort: createdAt desc/asc, dueDate asc, priority high→low
- [ ] LocalStorage persist
- [ ] Undo Delete: toast 5s + Hoàn tác, hết 5s xóa vĩnh viễn
- [ ] Không reload trang khi thao tác
- [ ] Validation: title required, dueDate không quá khứ khi tạo? (warn nếu quá hạn)

## 4. Success Metrics
- CRUD hoạt động không reload, state → render đúng
- Filter + sort kết hợp chính xác
- Dashboard số liệu khớp với tasks
- Reload trình duyệt vẫn giữ data (LocalStorage)
- Undo trong 5s khôi phục đúng vị trí
- Điểm rubric 100/100 (giao diện 10, CRUD 15, state 15, search 10, sort 10, dashboard 10, storage 10, validation 5, tách hàm 5, deadline 5, undo +5, no-reload +5)

## 5. Edge Cases & Constraints
- Title rỗng → báo lỗi inline, không cho submit
- Tags nhập "a, b, c" → trim, lowercase, loại rỗng, unique
- dueDate null → không tính quá hạn, sort để cuối
- Quá hạn = dueDate < today (00:00) và status !== done
- Xóa liên tiếp nhiều task → queue undo, mỗi toast riêng, timeout riêng
- LocalStorage quota / JSON parse lỗi → fallback []
- Filter tag "all" + search rỗng → hiện tất cả
- Sort priority: high(3) > medium(2) > low(1)
