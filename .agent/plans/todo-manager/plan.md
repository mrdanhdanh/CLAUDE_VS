## Data Model
```js
task = { id, title, description, priority: 'low'|'medium'|'high', status: 'todo'|'doing'|'done', dueDate: 'YYYY-MM-DD'|'' , createdAt: ISO, tags: string[] }
state = { tasks: task[], filters: {search, status, priority, tag, overdueOnly}, sortBy: 'newest'|'oldest'|'dueDate'|'priority' }
```

## Key Functions (tách riêng)
- `loadData()` / `saveData()` — localStorage `todo-manager:v1`
- `addTask(data)` / `updateTask(id, data)` / `deleteTask(id)` — mutate state only
- `filterTasks(tasks)` — search (title+description), status, priority, tag, overdueOnly
- `sortTasks(tasks)` — newest (createdAt desc), oldest asc, dueDate asc (null last), priority high→low
- `renderTasks()` — filtered+sorted → cards, empty state, count
- `renderDashboard()` — compute total/todo/doing/done/overdue
- `renderTagFilter()` — populate tag dropdown from tasks
- `openModal(task?)` / `closeModal()` / `handleSubmit()`
- `showUndoToast(task, index)` — 5s progress, Hoàn tác restores
- `isOverdue(task)` — dueDate < today 00:00 && status !== done

## Risks & Mitigations
| Risk | Mitigation |
|------|------------|
| LocalStorage JSON parse fail | try/catch fallback [] |
| dueDate empty sort | push null to end |
| Multiple undo toasts overlap | stack container, each with own timeout |
| Tag filter stale | re-render tag options on every render |
| Form validation miss | inline error, title required, trim |
| No reload requirement | all events preventDefault, state→render |
