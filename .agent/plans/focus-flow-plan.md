## Requirements
- Functional: Timer 25/5/15 với progress ring, Start/Pause/Reset, auto switch, sound+notification; Task CRUD + focus + done; Stats today + 7-day bars; Settings (durations, sound)
- Non-functional: Responsive 375/768/1280, states đầy đủ, animation 180ms, a11y AA, không layout shift, lưu localStorage

## Architecture
- **Single page** `focus-flow/index.html` + `styles.css` + `app.js` (ES module, không bundler)
- **State:** `state = { mode, durations, remaining, running, intervalId, tasks[], focusedId, stats:{date, pomodoros, minutes, done}, history:{date:count} }` — persist `localStorage focus-flow:v1`
- **Timer:** `Date.now()` diff để tránh drift khi tab ẩn; `requestAnimationFrame` hoặc `setInterval 250ms` update ring + title
- **Components:** Header, TimerCard (tabs + SVG circle + controls + focusing label), StatsRow (3 cards), Tasks (input + list), History (7 bars), Settings dialog, Toast
- **No deps:** Google Fonts Inter + Plus Jakarta Sans, CSS variables, SVG circle
