## 1. Vision
- **One-liner:** Cho agents bàn giao có rule (hand-off) + tự soi sau Verify fail (metacognition) — bắt đầu đơn giản, chưa group chat full.
- **Problem:** Agents chạy tuần tự cứng, `Implement` xong không biết khi nào cần `Polish`; Verify fail thì lặp nguyên output cũ (anti-pattern).
- **Target User:** Harness pipeline (Implement → Polish → Verify loop).

## 4. Success Metrics
- **Metric 1:** `handoff.mjs --from implement --to polish --reason "ui-changed"` → permitted + rule id
- **Metric 2:** `handoff.mjs --from implement --to foo` → refused unknown agent
- **Metric 3:** `reflect.mjs` sau fail lần 2 → strategy khác lần 1 (không lặp)
- **Metric 4:** `get_errors` pass, pipeline cũ không vỡ

## 5. Edge Cases & Constraints
- **Unknown agent:** fail rõ ràng với danh sách AGENTS
- **Reason rỗng:** vẫn pass nhưng warning (để visibility)
- **Constraint:** Node 18+, 0 deps
- **Persistence · F5 · Scope:** `experience.jsonl` là repo file (commit), F5 giữ, scope global
