## 2. Wireframe

### Handoff Flow
```
Implement done ──► handoff.mjs --from implement --to polish --reason "ui-changed"
                     │ check AGENTS + RULES
                     ├─► permitted (rule implement-polish-ui) → log audit (optional) → exit 0 + JSON {permitted, rule}
                     └─► refused (unknown agent / no rule) → exit 1 + JSON {permitted:false, reason}
```

### Rules (v1 explicit)
```js
RULES = [
  {id: "implement-polish-ui", from: "implement", to: "polish", when: reason.includes("ui")},
  {id: "implement-verify-default", from: "implement", to: "verify", when: always},
  {id: "polish-verify-default", from: "polish", to: "verify", when: always},
  {id: "verify-implement-fail", from: "verify", to: "implement", when: reason.includes("fail")},
  {id: "plan-implement-approved", from: "plan", to: "implement", when: reason.includes("approv")},
  {id: "explore-plan-default", from: "explore", to: "plan", when: always},
]
```

### Reflection Flow (Metacognition Lesson 09)
```
Verify fail (attempt N) ──► reflect.mjs --verify-output "..." --attempt N
                              │ analyze: lặp output? scope quá rộng? thiếu test?
                              ├─► strategy: "thu hẹp scope" | "đổi thứ tự" | "thêm test trước" | "đọc lại plan"
                              └─► append .agent/memory/experience.jsonl {ts, attempt, strategy, verifyOutput}
```

### Experience Record
```json
{"ts":"...","attempt":2,"strategy":"thu hẹp scope: chỉ sửa 1 file","verifyOutput":"...","prevStrategy":"..."}
```
