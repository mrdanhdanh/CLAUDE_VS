## 2. Wireframe

### Data Flow
```
plan.md (frontmatter YAML) ──► plan-validate.mjs parse ──► validate schema ──► --route → dispatcher map
                                    │                            │                      │
                                    │ fail → exit 1 + errors     │ pass → exit 0        │ {implement: [...], verify: [...]}
                                    └────────────────────────────┴──────────────────────┘
```

## 5. API Design

### `plan-validate.mjs`
```js
export const AGENTS = ["explore","plan","design","implement","polish","verify","yunie"]
export function parseFrontmatter(text): {frontmatter: object|null, body: string}
export function validatePlan(text): {valid: boolean, errors: string[], warnings: string[], plan: object|null}
export function routePlan(plan): {agent: subtasks[]}
// CLI:
node plan-validate.mjs --file .agent/plans/foo/plan.md
node plan-validate.mjs --file plan.md --route
node plan-validate.mjs --file plan.md --json
```

### Validation Rules
- `plan` phải là object, `main_task` string non-empty, `subtasks` array 1-10
- Mỗi subtask: `task_details` string non-empty (3-200 chars), `assigned_agent` in AGENTS
- `is_greeting` boolean optional (default false)
- Legacy (không frontmatter) → valid true + warning

## 6. Router (v1 rule-based)
```js
routePlan(plan) → {implement: [subtask...], verify: [...], ...}
// In ra dispatcher map để harness delegate
```
