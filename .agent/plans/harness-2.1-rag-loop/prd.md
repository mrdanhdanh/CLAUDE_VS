## 1. Vision
- **One-liner:** Nâng `search_library` từ 1-shot BM25 lên **vòng lặp maker-checker tự refine query tới khi đủ tốt** (max 3 vòng), như Lesson 05 Agentic RAG.
- **Problem:** Query kém / thiếu từ khóa → 0 hits hoặc hits kém → LLM bịa hoặc bỏ qua. Hiện chỉ 1-shot, không tự sửa.
- **Target User:** Harness agents (Explore, Plan, YUNIE) + dev gọi `search_library` qua MCP hoặc browser `window.LibrarySearch`.

## 4. Success Metrics
- **Metric 1:** Query `mcp a2a nlweb` 1-shot có thể 0 hits, nhưng `search_library_iterative` tự refine → có hits score >0 (verify bằng MCP call)
- **Metric 2:** Max 3 vòng, mỗi vòng log audit, không infinite loop (test bằng query vô nghĩa `xyzabc123`)
- **Metric 3:** Backward compat — `search_library` cũ vẫn pass, `get_status`/`list_books` không regression
- **Metric 4:** `get_errors` toàn workspace pass, `harness-manager status` pass

## 5. Edge Cases & Constraints
- **Empty query / chỉ stopwords:** trả lỗi `query rỗng` ngay, không loop
- **No enabled books / 0 chunks:** trả `hits: []` + `gap: no_data`, không loop
- **Query vô nghĩa:** sau 3 vòng vẫn 0 hits → trả `hits: []` + `rounds: 3` + `refinedQueries: [...]`
- **Performance:** BM25 <100ms mỗi vòng → 3 vòng <300ms, không block
- **Constraint:** Node 18+, 0 deps, reuse `tokenize`/`STOPWORDS` hiện có (minimal-ladder)
- **Persistence · F5 · Scope:** Không liên quan (không lưu `www/`), chỉ search runtime

## 6. Assumptions
- BM25 hiện tại đủ tốt, chỉ cần wrapper loop, không cần thay scoring
- Heuristic refiner đủ cho v1 (không cần LLM), LLM-as-judge để P1
- MCP stdio protocol giữ nguyên, chỉ thêm tool mới
- `export.json` đã có `AI-Agents-for-Beginners-Distilled.md` 25 chunks (đã verify)
