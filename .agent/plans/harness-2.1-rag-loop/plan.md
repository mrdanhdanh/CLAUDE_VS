## 1. Architecture

**Stack:** Node 18+ ESM, 0 deps, reuse BM25 (K1=1.2, B=0.75) + STOPWORDS hiện có. Module `rag-loop.mjs` pure functions, dùng được cả Node (MCP) và browser (app.js).

```
www/library/
  rag-loop.mjs          ← MỚI: pure BM25 + agentic loop (Node + browser)
  mcp-server.mjs        ← SỬA: import rag-loop, thêm tool search_library_iterative
  app.js                ← SỬA: thêm window.LibrarySearch.searchIterative + toggle
  search.mjs            ← không đụng (P1)
  export.json           ← không đụng (data)
```

**Data flow:** `agenticSearch(query, chunks, registry, opts)` → loop max 3 → `evaluateGap` (minHits=2, minScore=1.0) → `refineQuery` (attempt 1: original, 2: synonym expand, 3: split tokens) → return `{hits, rounds, refinedQueries, gap}`

## 3. Risks & Mitigations

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Loop vô hạn | Low | High | Max 3 vòng hard cap, early return khi no gap |
| Refine không cải thiện | Medium | Medium | Attempt 3 fallback split tokens + merge hits |
| Import ESM vỡ MCP (Node) | Medium | High | `rag-loop.mjs` là ESM thuần, `mcp-server.mjs` đã là ESM (`import`), test `node mcp-server.mjs` ngay sau edit |
| Browser import fail (file://) | Low | Medium | `app.js` dùng dynamic `import()` hoặc inline fallback nếu `import` fail |
| Regression `search_library` cũ | Low | High | Giữ nguyên handler cũ, chỉ thêm tool mới, test cả 2 |
