## 2. Wireframe

### Trace Flow
```
trace.mjs start --task "p1-2" ──► traceId (hex 8) ──► .agent/traces/<id>.json {traceId, task, startedAt, spans:[]}
trace.mjs span --trace <id> --phase implement ──► spanId ──► append {spanId, phase, startedAt}
audit.mjs log --traceId <id> --spanId <sid> ──► event có traceId/spanId
trace.mjs end --trace <id> ──► {endedAt, durationMs}
```

### Eval Gate Flow
```
eval-gate.mjs --scope www/library
  ├─► node --check www/library/*.mjs (syntax)
  ├─► MCP smoke: search_library + search_library_iterative + get_status
  ├─► plan-validate smoke: P0-1/P0-2/P0-3 legacy pass
  └─► exit 0 (pass) / 1 (fail) + JSON report
```

### CI
```yaml
jobs:
  eval:
    runs-on: ubuntu-latest
    steps:
      - checkout, setup-node 18
      - run: node .github/harness/scripts/eval-gate.mjs --scope www/library
  deploy:
    needs: eval
```
