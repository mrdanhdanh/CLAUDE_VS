> **Version:** 2.1-P1-2 · **Ngày:** 2026-09-04 · **Tác giả:** YUNIE
> **Nguồn:** `AI-Agents-for-Beginners-Distilled.md` Lesson 10 Production + `docs/harness-2.1-upgrade.md` §5.5
> **Baseline:** Harness 2.0 — `audit.jsonl` (hash+sig) + `get_errors`, chưa có traceId/span, chưa có eval gate

## 1. Vision
- **One-liner:** Mỗi harness run là 1 trace, mỗi phase là 1 span (traceId/spanId trong audit) + eval gate offline trước deploy `www/`.
- **Problem:** Không observability = black box; có = glass box (Lesson 10). Hiện chỉ có audit rời rạc, không trace xuyên suốt.
- **Target User:** Verify agent, CI, YUNIE STATUS.

## 4. Success Metrics
- **Metric 1:** `trace.mjs start` → traceId, 2 spans → file `.agent/traces/*.json` đúng
- **Metric 2:** `audit.mjs log --traceId X --spanId Y` → event có trace, `verify` vẫn OK
- **Metric 3:** `eval-gate.mjs --scope www/library` → pass (hiện tại)
- **Metric 4:** `pages.yml` có job eval, `get_errors` pass

## 5. Edge Cases & Constraints
- **No trace:** audit log không trace vẫn pass (backward compat)
- **Eval fail:** exit 1, CI block deploy
- **Constraint:** Node 18+, 0 deps
- **Persistence:** `.agent/traces/` commit? Không — gitignore (ephemeral), chỉ `status.json` commit

## 6. Assumptions
- File-based trace đủ cho v1, OTel để P2
- Eval offline = smoke checks (không cần dataset lớn v1)
