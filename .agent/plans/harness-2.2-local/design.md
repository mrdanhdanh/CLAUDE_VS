## 2. Wireframe

### Locality Routing (Lesson 17 hybrid table)
```
query ──► routeLocality:
  sensitive (password, token, secret, private, personal) → local
  offline keywords (offline, plane, outage, local-only) → local
  simple bounded (≤3 tokens, no complex) → local
  hard multi-hop (plan trip, compare 3+, analyze codebase) → cloud
  else → local (default privacy-first)
```

### Local Status + Chat
```
local.mjs status → GET {endpoint}/models (10s timeout) → {available, endpoint, model, latencyMs}
local.mjs chat --prompt "..." → POST {endpoint}/chat/completions (OpenAI-compatible)
  ├─► success → {backend: "local", ...}
  └─► fail → {backend: "cloud-fallback", reason} (v1: flag, chưa gọi cloud thật)
```

### Router Integration
```js
// router.mjs thêm:
export function routeLocality(query) // → "local" | "cloud"
```
