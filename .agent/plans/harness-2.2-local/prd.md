## 1. Vision
- **One-liner:** Hybrid local-first — SLM orchestrate + tools do heavy lifting, OpenAI-compatible endpoint (`http://localhost:PORT/v1`), fallback cloud khi local fail/offline-outage.
- **Problem:** Mọi reasoning đều cần cloud (tốn token, lộ data, outage thì chết). SLM vài B params yếu multi-hop nhưng đủ cho bounded tasks nếu tools làm nặng.
- **Target User:** Privacy/offline tasks, simple bounded queries, graceful degradation khi outage.

## 4. Success Metrics
- **Metric 1:** `local.mjs status` không có server → `available:false` (không crash)
- **Metric 2:** `routeLocality("my password reset")` → local (sensitive), `routeLocality("plan 3-day multi-hop trip")` → cloud
- **Metric 3:** `chat` khi local fail → fallback cloud flag (mock), log rõ
- **Metric 4:** `get_errors` pass, router cũ không vỡ

## 5. Edge Cases & Constraints
- **No server:** mọi lệnh local đều graceful (không throw), trả `available:false`
- **Secret:** local chat không log prompt raw (chỉ lengths/hashes)
- **Constraint:** Node 18+, 0 deps, `fetch` built-in, timeout 10s
- **Env:** `FOUNDRY_LOCAL_ENDPOINT` (default `http://localhost:12434/v1`), `FOUNDRY_LOCAL_MODEL` (default `qwen2.5-7b-instruct`)
