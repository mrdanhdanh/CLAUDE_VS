# Design mini — Slop Gate

**slop-check.mjs (gate):**
```
node scripts/slop-check.mjs <files...>   # gate: exit 1 nếu findings
node scripts/slop-check.mjs --scan       # audit: quét roots mặc định, exit 0
Flags: --min-lines 8 · --max-func 80 · --max-cc 12 · --top 10 · --json · --strict
```
- **Dup:** chuẩn hóa dòng (trim + collapse space), bỏ dòng trivial/comment; group theo hash → pair cùng hash → extend chạy tối đa → run ≥ min-lines; dedupe region chứa nhau; hỗ trợ cross-file.
- **Func:** scanner brace-depth theo dòng (strip string/comment đơn giản); block bắt đầu ở depth 0→1 với header function-ish (loại trừ if/for/while/switch/catch/else); đếm complexity (if/else/for/while/case/catch/&&/||/??); block ≥10 dòng mới xét.
- **Skip:** node_modules/vendor/.git/.claude/.disabled/bin/obj/publish/test-results/playwright-report; file có marker "DO NOT EDIT"/"generated by" ở 3 dòng đầu; .min.js.
- **Output:** text có emoji + preview dòng; `--json` cho máy. Giới hạn top findings.
