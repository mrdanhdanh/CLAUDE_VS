# Publish — Space Bunny Free (TikTok)

> Chuẩn bị nội dung đăng cho clip `www/space-bunny-free/space-bunny-free-50s.mp4`.
> **Chưa đăng gì** — file này chỉ là bộ gợi ý để user tự quyết.

## Ràng buộc quan trọng (2026)

| Điều | Chi tiết | Nguồn |
|---|---|---|
| **Chỉ 5 hashtag đầu được tính** | Từ update 8/2025, TikTok chỉ đăng ký 5 hashtag đầu trong caption; gõ thêm không có tác dụng phân loại/phân phối | CloutMap 4/2026 |
| **3–5 là tối ưu** | Buffer: 3–5 · Sprout Social: 3–6 · phân tích thuật toán: 3–5 | Akselera tổng hợp |
| **Caption quan trọng hơn hashtag** | TikTok index **chữ trong caption** cho search; hashtag chỉ là tín hiệu phân loại | CloutMap + Akselera |
| **Niche thắng broad** | Hashtag niche (10K–500K view) cho engagement cao hơn 60–70% so với broad | Akselera |

**Điểm tranh chấp — `#fyp`:** CloutMap nói thẳng "đừng dùng, phí 1 slot, không tạo tín hiệu phân loại". Akselera lại khuyên "tối đa 1 biến thể FYP" kèm bảng dữ liệu cho thấy "1 FYP + 4 niche" tốt nhất. **Khuyến nghị ở đây: bỏ `#fyp`** — lập luận cơ chế (5 slot + không có category signal) rõ hơn là bảng số không kiểm chứng được.

## Lợi thế sẵn có của clip này

Clip **đã** đưa keyword vào cả 3 kênh mà TikTok index:
- **Chữ trên hình** (OCR đọc được): `Space Bunny`, `space-bunny-free`, `1M CONTEXT`, `MULTIMODAL`
- **Lời đọc** (ASR chuyển thành text): các từ khoá trên được nói rõ trong voiceover
- **Caption** (bên dưới) — bổ sung phần còn thiếu

→ Nghĩa là caption không phải "gánh" hết; chỉ cần khớp và củng cố.

## Bộ hashtag — 3 set để A/B test

Mỗi set đúng 5 tag (khớp giới hạn 5 slot). **Đừng dùng cùng 1 set cho mọi video** — TikTok coi là lặp lại/spam và bóp reach.

### Set A — "AI Việt" (khuyên dùng cho clip này)

```
#ai #aivietnam #opencode #spacebunny #laptrinh
```

| Slot | Tag | Vai |
|---|---|---|
| Niche | `#ai` | Nhóm nội dung rộng nhất, đúng ngành |
| Sub-niche | `#aivietnam` | Khoanh audience Việt quan tâm AI |
| Sub-niche | `#opencode` | Đúng sản phẩm — người đang dùng OpenCode sẽ tìm |
| Branded | `#spacebunny` | Gần như 0 cạnh tranh; sau này ai search đều thấy clip này |
| Nội dung | `#laptrinh` | Kéo đúng tệp dev Việt |

### Set B — "Tin công nghệ"

```
#congnghe #ai #tintuc #opencode #spacebunny
```

### Set C — "Dev quốc tế" (test reach ngoài VN)

```
#ai #opensource #llm #opencode #spacebunny
```

> Set C chỉ nên dùng nếu caption có thêm tiếng Anh — clip đang thuyết minh tiếng Việt nên đây là **thử nghiệm**, không phải set chính.

### Không nên dùng

| Tag | Lý do |
|---|---|
| `#fyp` `#foryou` `#foryoupage` | Chiếm slot mà không tạo tín hiệu phân loại (xem phần tranh chấp ở trên) |
| `#followme` `#like4like` `#sub4sub` | Nhóm rủi ro shadowban cao (~80%) |
| `#viral` `#trending` | Quá oversaturated, không giúp phân loại |
| Tag không liên quan (vd `#chatgpt`, `#claude`) | Thuật toán phát hiện hashtag lệch nội dung → giảm reach |

## Checklist trước khi đăng

- [ ] Caption có keyword chính ở câu đầu? (OpenCode · Space Bunny · model ẩn danh)
- [ ] Đúng 5 hashtag, **tất cả nằm trong caption** (để trong comment chỉ còn 30–40% trọng số)
- [ ] Mỗi tag kiểm tra nhanh: search trên TikTok, tag nào ra 0 kết quả = có thể đã bị ban → bỏ
- [ ] Caption không claim gì ngoài những gì clip đã nói (giữ đúng content guard trong `plan.md`)
- [ ] Set hashtag khác với video trước đó
- [ ] Bật phụ đề (auto-caption) để củng cố keyword cho phần lời đọc
