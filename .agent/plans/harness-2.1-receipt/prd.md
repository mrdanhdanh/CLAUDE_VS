# PRD: Harness 2.1 — P0-4 Receipt Ed25519 + JCS (Lesson 18)

> **Pipeline:** Harness 8 phase

## 1. Vision
- **One-liner:** Nâng `audit.jsonl` từ SHA-256/16 lên **receipt ký Ed25519 + JCS canonical JSON + hash chain** để auditor chỉ cần public key là verify được, sửa 1 byte → fail.
- **Problem:** Hash-chain hiện chỉ tamper-evident nội bộ, không có chữ ký → ai có write access cũng tạo chain giả được. Chưa có canonical JSON → verify không deterministic.
- **Target User:** Governance (policy-check, audit verify), auditor ngoài, CI gate.

## 3. Scope

### In Scope (P0 — phải có)
- [ ] JCS canonical JSON (RFC 8785 subset) trong `audit.mjs`: sort keys, no whitespace, UTF-8, number normalize
- [ ] Ed25519 sign/verify bằng `node:crypto` (Node 18+ có `crypto.sign(null, data, privateKey)` với `ed25519`) — 0 deps
- [ ] Keypair management: `audit.mjs keygen` (tạo ed25519, lưu vào `credentials.enc.json` via `credentials.mjs` hoặc file `.agent/audit.key` gitignore), `audit.mjs pubkey` (in public key)
- [ ] `audit.mjs log` thêm `sig` (base64url) + `pub` (base64url public key, hoặc key id)
- [ ] `audit.mjs verify` check: hash-chain (cũ) + JCS canonical + Ed25519 signature (mới). Legacy events (không sig) → `legacy` count, không fail
- [ ] Tests: log → verify pass, sửa 1 byte → fail, legacy vẫn pass

### Nice to Have (P1)
- [ ] `audit.mjs verify --pubkey <key>` để auditor ngoài verify bằng public key riêng
- [ ] Receipt chaining: mỗi receipt chứa hash của receipt trước (đã có prevHash, giữ)

### Non-Goals
- Thay đổi `policy.json`, thêm rule mới (P1 khác)
- HSM / remote signer (chỉ local keypair v1)

## 4. Success Metrics
- **Metric 1:** `audit.mjs log` → event có `sig` + `pub`, `verify` → `chain OK + sig OK`
- **Metric 2:** Sửa 1 byte `target` trong `audit.jsonl` → `verify` fail, chỉ rõ line
- **Metric 3:** Legacy events (không sig) → `legacy` count, không fail
- **Metric 4:** `get_errors` pass, `policy-check --check` pass

## 5. Edge Cases & Constraints
- **No keypair:** `log` tự `keygen` lần đầu (lưu `.agent/audit.key` gitignore + public trong event), warning 1 lần
- **Key mất:** events cũ vẫn verify bằng `pub` trong event (mỗi event mang pub của nó) — không cần key hiện tại
- **JCS:** chỉ canonicalize payload đã ký (không gồm `sig` itself), sort keys recursive, array giữ order
- **Constraint:** Node 18+, 0 deps, dùng `node:crypto` Ed25519 (có từ Node 12+)
- **Secret:** private key never logged, `redactTarget` đã có, thêm redact cho `sig`? Không — `sig` là public, log được

## 6. Assumptions
- `node:crypto` hỗ trợ `ed25519` trên máy dev (Node 18+ mặc định có OpenSSL 3)
- Mỗi event mang `pub` riêng → verify độc lập, không cần keyring
- Backward compat: `verify` cũ vẫn pass với events mới (hash-chain giữ nguyên)
