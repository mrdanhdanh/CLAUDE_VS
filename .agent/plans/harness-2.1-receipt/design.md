## 2. Wireframe

### Data Flow
```
audit.mjs log ──► build event (ts, actor, tool, target, decision, rule, ...) ──► prevHash ──► hash (SHA-256/16, giữ) ──► canonicalize(payload) ──► sign Ed25519 ──► sig + pub ──► append JSONL
audit.mjs verify ──► read lines ──► check hash-chain (cũ) ──► check JCS + Ed25519 (mới, nếu có sig) ──► report {total, chained, sigOk, sigFail, legacy, broken}
```

### Payload Đã Ký (JCS)
```json
{
  "ts": "...", "actor": "...", "tool": "...", "target": "...",
  "decision": "...", "rule": null, "durationMs": null, "error": null,
  "intent": null, "requestId": "...", "prevHash": "...", "hash": "..."
}
```
- Canonicalize: sort keys recursive, `JSON.stringify` không whitespace, UTF-8. Không gồm `sig`/`pub`.
- Ký: `crypto.sign(null, Buffer.from(canonical, 'utf8'), privateKey)` → base64url `sig`.
- Verify: `crypto.verify(null, Buffer.from(canonical, 'utf8'), publicKey, Buffer.from(sig, 'base64url'))`.

### Keypair
- `audit.mjs keygen` → `crypto.generateKeyPairSync('ed25519')` → export PKCS8 DER base64 → lưu `.agent/audit.key` (0600, gitignore) + public SPKI DER base64.
- `log` lần đầu không thấy key → tự `keygen` + warning.
- Mỗi event mang `pub` (base64 SPKI DER) để verify độc lập.

## 4. CLI

```bash
node .agent/scripts/audit.mjs keygen          # tạo keypair
node .agent/scripts/audit.mjs pubkey          # in public key
node .agent/scripts/audit.mjs log --tool read --target "www/x" --decision permitted
node .agent/scripts/audit.mjs verify          # check chain + sig
node .agent/scripts/audit.mjs verify --json
```

## 5. Verify Logic
- Legacy (không `sig`): `legacy++`, chỉ check hash-chain như cũ.
- Có `sig`: check hash-chain + JCS canonical + Ed25519. Fail sig → `sigFail++`, `broken++`.
- Sửa 1 byte `target` → hash mismatch + sig mismatch → fail, chỉ rõ line.
