# PRD: Liquid Glass Status — Rainbow Hover

> Task: đổi giao diện trang status thành liquid glass, khi hover lên vùng nào thì cho rainbow border động

## 1. Vision
- **One-liner:** Biến `www/index.html` STATUS thành giao diện **Liquid Glass** (Apple iOS 26) — mọi card/section là kính mờ, hover thì hiện **viền cầu vồng xoay** (conic-gradient animated).
- **Problem:** Giao diện hiện tại flat trắng, thiếu cảm giác premium; hover chỉ đổi shadow, chưa có điểm nhấn.
- **Target User:** Dev/visitor mở STATUS dashboard trên desktop/mobile, muốn cảm giác hiện đại, mượt, vẫn đọc rõ data.

## 3. Scope

### In Scope (P0 — phải có)
- [ ] Thêm design tokens glass + rainbow vào `:root` (`--glass-*`, `--rainbow`, `--angle` via @property)
- [ ] Body background thành mesh gradient để glass có gì để sample (giữ light theme)
- [ ] Header → liquid glass (blur 16px, saturate 180%, rim highlight)
- [ ] Tất cả card/section chính → glass: `hero-card`, `mini-card`, `stat`, `card`, `yunie-hero`, `yunie-letter-card`, `reg-card`, `page-link`, `preset/plan` containers, `modal-panel`
- [ ] Rainbow border động **chỉ khi hover** (pseudo ::before + conic-gradient + mask, animation rotate 3s linear, opacity 0→1, paused→running)
- [ ] Hover cũng áp dụng cho table rows? Không — chỉ block cards/sections (tránh nhiễu)
- [ ] A11y: `prefers-reduced-motion` tắt xoay, `prefers-reduced-transparency` giảm blur, focus-visible vẫn rõ
- [ ] Giữ responsive 375/768/1280, không vỡ

### Nice to Have (P1)
- [ ] Glass tint nhẹ cho hero (primary tint 6%)
- [ ] Subtle inner highlight + shadow cho depth
- [ ] Rainbow glow nhẹ (blur) khi hover (optional, opacity thấp)

### Non-Goals (Out of Scope)
- Không đổi logic `app.js` / `status.json` / data fetch
- Không đổi layout/grid, chỉ material + border
- Không thêm lib JS, chỉ CSS
- Không đổi dark mode (giữ light)

## 4. Success Metrics
- 100% card chính có glass (visual check)
- Hover bất kỳ card → viền cầu vồng xoay mượt 60fps, không layout shift
- Lighthouse a11y ≥95, contrast pass
- `get_errors` 0, `prefers-reduced-motion` test pass
- Responsive 375/768/1280 không vỡ, backdrop-filter fallback hiển thị solid

## 5. Edge Cases & Constraints
- Browser không hỗ trợ `backdrop-filter` → fallback solid white + border
- `mask-composite: exclude` cần `-webkit-mask-composite: xor` cho Safari
- Nhiều `backdrop-filter` gần nhau → gom? Nhưng cards cách nhau nên ok, không cần shared surface
- Rainbow border không được che content → `pointer-events:none`, `inset:0`, `padding: var(--border-w)`
- Animation phải dùng `@property --angle` để xoay mượt, không dùng `transform: rotate` trên pseudo

## 6. Assumptions
- Giữ light theme, không thêm dark toggle
- Glass fill `rgba(255,255,255,0.68)` đủ contrast trên mesh gradient
- Rainbow 7 màu Apple: #ff3b30 → #ff9500 → #ffcc02 → #34c759 → #007aff → #af52de → #ff3b30
