# PRD: WEB 011 Part 8 — Real PWA + Real Permissions

> Part 8 — Hoàn thiện 2 stub còn lại từ Part 1: Service Worker cache thật + offline page, Permission Manager gọi API thật.

## 1. Vision
- **One-liner:** Biến WEB UNIVERSE từ "demo có SW stub" thành PWA thật — cache offline được, permission request thật (không toggle giả).
- **Problem:** `sw.js` vẫn là stub network-first không cache (comment "Part 6 sẽ thêm" nhưng chưa làm); `permission-manager.js` request chỉ toggle state giả, chưa gọi `Notification.requestPermission` / `getUserMedia` / `geolocation`.
- **Target User:** Người mở app offline → vẫn dùng được; bấm Request Camera → prompt thật của trình duyệt.
- **Persistence:** `localStorage` (giữ nguyên) · Cache Storage (SW v2) · **F5: giữ** · **Scope: per-browser**.

## 3. Scope
### In Scope (P0)
- [ ] `sw.js` v2: precache core assets (index.html, css, js core, manifest, offline.html), cache-first cho static, network-first cho HTML navigation, fallback `offline.html`
- [ ] `offline.html`: trang offline fallback cùng design system (dark/light, CSS variables)
- [ ] `permission-manager.js`: request thật — Notification, getUserMedia (camera/mic, stop tracks sau test), geolocation, clipboard; query sync Permissions API
- [ ] `pwa-lab/index.js`: bỏ text "stub", hiện cache thật + nút "Clear caches"
### Non-Goals
- Không thêm module mới (YAGNI — hoàn thiện trước khi thêm)
- Không background sync / push notification
- Không đổi kiến trúc core

## 4. Success Metrics
- M1: DevTools Offline → reload → app vẫn load (hoặc offline.html cho navigation)
- M2: Cache Storage có `web-universe-v2` với entries
- M3: Request Camera → prompt thật; deny → state `denied`
- M4: PWA Lab không còn chữ "stub"

## 5. Edge Cases
- EC1: SW fetch lỗi non-HTML → trả lỗi gốc, không cache
- EC2: getUserMedia deny → trả `denied`, không crash
- EC3: file:// protocol → SW không chạy, app vẫn hoạt động như cũ (guard đã có)
- EC4: Cache version bump → old cache tự xóa ở activate
