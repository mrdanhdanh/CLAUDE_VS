# Design: N5 Blazor — Liquid Glass + Glowing Rainbow Border

## 1. Design System

### Palette (Liquid Glass + Rainbow)
- **Glass base:** `rgba(255,255,255,0.08)` backdrop-filter blur 16-24px, border `rgba(255,255,255,0.18)`
- **Primary:** `#6366f1` (indigo) — CTA, active nav
- **Secondary:** `#0ea5e9` (sky) — accent
- **Rainbow:** conic-gradient `#ff3b30 → #ff9500 → #ffcc02 → #34c759 → #007aff → #af52de → #ff3b30` (animated --angle 3s linear infinite)
- **Surface:** `#0f172a` (slate-900) dark bg, `#f8fafc` light bg
- **Text:** `#f1f5f9` on dark, `#0f172a` on light
- **Success/Warning/Danger:** `#16a34a` / `#f59e0b` / `#dc2626`

### Typography
- **Display/JP:** `Noto Sans JP`, `Zen Maru Gothic` (Google Fonts) for Kana/Kanji
- **Body/UI:** `Inter`, `Geist Sans` — 14/16/20/24/32 scale
- **Mono:** `JetBrains Mono` for romaji

### Spacing & Radius
- Spacing: 4/8px scale (4,8,12,16,24,32,48)
- Radius: 12px cards, 16px glass panels, 9999 pill
- Shadow: soft `0 8px 32px rgba(0,0,0,0.12)` + glass inner highlight

### Tokens (CSS variables)
```css
--glass-bg: rgba(255,255,255,0.08);
--glass-border: rgba(255,255,255,0.18);
--glass-blur: 20px;
--rainbow: conic-gradient(from var(--angle), #ff3b30, #ff9500, #ffcc02, #34c759, #007aff, #af52de, #ff3b30);
--radius-lg: 16px;
--shadow-glass: 0 8px 32px rgba(0,0,0,0.12);
```

## 2. Liquid Glass + Rainbow Border — Spec

### Glass Card
- `background: var(--glass-bg); backdrop-filter: blur(var(--glass-blur)) saturate(1.4); -webkit-backdrop-filter`
- `border: 1px solid var(--glass-border); border-radius: var(--radius-lg); box-shadow: var(--shadow-glass)`
- Inner highlight: `inset 0 1px 0 rgba(255,255,255,0.15)`

### Rainbow Border (Glowing)
- Wrapper `.rainbow-wrap` with `padding: 1.5px; border-radius: calc(var(--radius-lg) + 1.5px); background: conic-gradient(from var(--angle,0deg), ...)`
- Animated via `@property --angle { syntax: "<angle>"; initial-value: 0deg; inherits: false; }` + `@keyframes rotate { to { --angle: 360deg; } }`
- Glow: `filter: drop-shadow(0 0 8px rgba(99,102,241,0.4))` on hover, `transition: 300ms`
- Fallback: if no @property, JS sets `--angle` via rAF on `<html>`
- Use sparingly: only on primary cards, active nav, CTA buttons — not every element

## 3. Layout & Wireframes

### Shell
```
┌─────────────────────────────────────────────┐
│ TopBar (glass, sticky)  Logo | Nav | Progress│
├──────────┬──────────────────────────────────┤
│ Sidebar  │  Main Content (glass panels)     │

│ - Kanji  │  │ Purpose/Structure/Tech/Feat│  │
│ - Vocab  │  ├────────────────────────────┤  │
│ - Grammar│  │ Content Grid/Cards         │  │

│ - Progress│ └────────────────────────────┘  │
└──────────┴──────────────────────────────────┘
```

### Responsive
- **375px:** Sidebar collapses to bottom tab bar / hamburger drawer; content single column; helper stacked
- **768px:** Sidebar 220px, content 2-col grid
- **1280px:** Sidebar 260px, content 3-col grid, helper side panel option

### Pages
1. **Home/Dashboard:** Hero glass + stats (kanji learned, vocab, streak) + quick actions + roadmap
2. **Kana:** Tabs Hira/Kata, grid 46 chars, click → modal detail (stroke, romaji, audio), quiz mode
3. **Kanji:** Filter by lesson, cards with on/kun, meaning, example, stroke count, bookmark
4. **Vocabulary:** Search + filter by topic, flashcard flip, list/table toggle
5. **Grammar:** List patterns (~30), expand detail (formation, examples, exercise)
6. **Practice/Test:** Quiz engine (choice, fill-blank), timer, result + review
7. **Progress:** Charts (circular progress), streak calendar, export

## 4. Components

- `GlassCard.razor` — base glass container
- `RainbowCard.razor` — GlassCard + rainbow border wrapper
- `FlashCard.razor` — flip animation (transform 300ms)
- `QuizRunner.razor` — EditForm + validation + result
- `ProgressRing.razor` — SVG circular progress
- `KanaGrid.razor`, `KanjiCard.razor`, `VocabCard.razor`, `GrammarCard.razor`

## 5. States
- **Loading:** shimmer glass skeleton
- **Empty:** illustration + CTA
- **Error:** glass alert with retry
- **Hover/Focus/Active/Disabled:** defined per component, focus-visible ring `2px solid #6366f1`

## 6. Motion
- Page transition: fade 200ms
- Card hover: lift `translateY(-2px)` + shadow, 200ms ease
- Flip: `rotateY(180deg)` 300ms
- Rainbow: 3s linear infinite (only on highlighted elements)

## 7. A11y
- Contrast ≥4.5:1, keyboard nav, aria-labels, skip-link, focus-visible
- Kana/Kanji have `lang="ja"` and aria
