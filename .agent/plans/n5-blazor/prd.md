# PRD: N5 Blazor — Website học JLPT N5 cho người mới bắt đầu

## 1. Vision
- **One-liner:** Website học JLPT N5 toàn diện cho người mới bắt đầu, xây bằng Blazor Web App (.NET 8/10) với giao diện Liquid Glass + Glowing Rainbow Border, mỗi trang đều có Helper giải thích rõ mục đích/cấu trúc/kỹ thuật/tính năng.
- **Problem:** Người mới học N5 thiếu nơi học tập trung, trực quan, có lộ trình rõ ràng (Kana → Kanji → Từ vựng → Ngữ pháp → Luyện thi), thiếu giải thích kỹ thuật cho người học dev muốn hiểu Blazor.
- **Target User:** Người mới bắt đầu tiếng Nhật (0 → N5), sinh viên IT muốn tham khảo Blazor best practices, giáo viên cần demo.

## 3. Scope

### In Scope (P0 — phải có)
- [ ] Blazor Web App (Server interactivity, SSR, Streaming) — .NET 8/10
- [ ] Layout: NavMenu + TopBar + Liquid Glass shell + Rainbow border accents
- [ ] 7 trang chính: Home/Dashboard, Kana (Hira/Kata), Kanji, Vocabulary, Grammar, Practice/Test, Progress
- [ ] Mỗi trang có `<PageHelper>` component: Purpose / Structure / Techniques / Features (4 mục)
- [ ] Services: `IKanaService`, `IKanjiService`, `IVocabService`, `IGrammarService`, `IQuizService`, `IProgressService` (DI Singleton/Scoped)
- [ ] Models: Kana, Kanji, Vocab, GrammarPattern, QuizQuestion, UserProgress
- [ ] Interactivity: flashcards, quiz, search/filter, bookmark, progress tracking (localStorage via JS interop)
- [ ] Forms & Validation: quiz form với `EditForm` + `DataAnnotationsValidator`
- [ ] Liquid Glass design system + Rainbow border (conic-gradient animated, hover glow)
- [ ] Responsive 375/768/1280, a11y, loading/empty/error states
- [ ] Tests: xUnit + bUnit cho services & components

### Nice to Have (P1)
- [ ] Audio phát âm (Web Speech API fallback)
- [ ] Export progress JSON
- [ ] PWA offline

### Non-Goals
- Không làm backend DB thật (dùng in-memory + localStorage)
- Không làm N4-N1 (chỉ N5)
- Không làm auth/login phức tạp

## 4. Success Metrics
- Build `dotnet build` PASS, `dotnet test` PASS
- 7 trang đều render, mỗi trang có Helper đầy đủ 4 mục
- Lighthouse: responsive không vỡ, contrast ≥4.5:1, keyboard navigable
- Quiz chấm điểm đúng, progress lưu được

## 5. Edge Cases & Constraints
- Không có audio file → dùng Web Speech API hoặc placeholder
- localStorage chưa có → khởi tạo default progress
- Search rỗng → empty state
- Blazor Server cần SignalR — đảm bảo `MapRazorComponents().AddInteractiveServerRenderMode()`

## 6. Assumptions
- Dùng .NET 8 SDK (ổn định) với `blazor` template interactivity Server
- Dữ liệu N5 hardcode trong services (không fetch API ngoài)
- Deploy static không cần — chạy `dotnet run` là xem được
