## 1. Architecture

**Stack:** Node 18+ ESM, 0 deps, reuse BM25/STOPWORDS (minimal-ladder). Module `tool-registry.mjs` pure, dùng được cả Node (MCP) và browser (app.js).

```
www/library/
  tool-registry.mjs     ← MỚI: schemas + validate + approval + history (Node+browser)
  rag-loop.mjs          ← đã có (P0-1)
  mcp-server.mjs        ← SỬA: import tool-registry, validate trước handle
  app.js                ← SỬA: import tool-registry, validate trước search
  export.json           ← không đụng
```

**Data flow:** `validateParams(tool, args)` → `normalizeArgs` (fill defaults + clamp) → `checkApproval` → `execute` → `toolHistory.push` → return

**Reuse-first:**
- Reuse `STOPWORDS`/`K1`/`B` không đụng
- Không thêm dependency, không đổi BM25
