## 2. Wireframe

### Router + Cache Flow
```
query ──► normalize ──► cache.get? ──► hit → return (cached:true)
              │              └─► miss → routeQuery → fast (1-shot BM25) | deep (agenticSearch 3 vòng)
              │                              │                                    │
              └─► cache.set (TTL 5m, max 50) ◄────────────────────────────────────┘
```

### routeQuery Heuristic
```js
COMPLEX_TOKENS = [mcp, a2a, nlweb, rag, planning, multi, agent, metacognition, memory, context, receipt, observability, deploy, framework, protocol, tool, trustworthy, browser, local]
tokens = tokenize(query)
if tokens.length <= 2 → fast (trừ khi có COMPLEX_TOKENS)
else if any token in COMPLEX_TOKENS → deep
else if tokens.length <= 3 → fast
else → deep
```

### Deploy Lifecycle
```
deploy-check.mjs
  ├─► version pin (mcp-server 1.1.0 == catalog library 1.1.0)
  ├─► eval-gate --scope www/library (offline gate)
  └─► audit verify (chain OK)
  → exit 0 (deploy) / 1 (block)
```
