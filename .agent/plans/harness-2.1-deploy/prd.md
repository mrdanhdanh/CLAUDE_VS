## 1. Vision
- **One-liner:** Deploy scalable cho library RAG — model router (simple→fast, complex→deep) + response cache + concurrency bound + lifecycle.
- **Problem:** Mọi query đều chạy full BM25 + 3 vòng loop, kể cả câu lặp; không phân loại complexity; không cache.
- **Target User:** Library users (browser + MCP), CI deploy.

## 3. Scope

### In Scope (P0 — phải có)
- [ ] `www/library/router.mjs` — **MỚI**: `routeQuery(query)` heuristic (simple: ≤3 tokens hoặc stopwords-only → fast; complex: có từ chuyên môn → deep), `cachedSearch` wrapper (Map, TTL 5m, max 50)
- [ ] Sửa `www/library/app.js` — dùng router: simple → `bm25Search` 1-shot, complex → `agenticSearch`; cache trước khi search
- [ ] Sửa `www/library/mcp-server.mjs` — thêm `route` vào `search_library_iterative` response (`routed: fast|deep`), cache MCP in-memory
- [ ] `.github/harness/scripts/deploy-check.mjs` — **MỚI**: lifecycle check (version pin + eval-gate + audit verify), exit 0/1
- [ ] Tests: router simple/complex, cache hit/miss/TTL, deploy-check pass

## 4. Success Metrics
- **Metric 1:** `routeQuery("hi")` → fast, `routeQuery("mcp a2a nlweb planning")` → deep
- **Metric 2:** Gọi 2 lần cùng query → lần 2 cache hit, nhanh hơn
- **Metric 3:** `deploy-check.mjs` → pass (version + eval + audit)
- **Metric 4:** `get_errors` pass, backward compat

## 5. Edge Cases & Constraints
- **Cache key:** normalize query (lowercase trim) + top_k + enabled_only
- **TTL:** 5 phút, max 50 entries (LRU đơn giản: xóa cũ nhất)
- **Constraint:** Node 18+, 0 deps, browser + Node compatible
- **Persistence:** Cache in-memory only (F5 mất) — persist để P1

## 6. Assumptions
- Heuristic router đủ cho v1 (không cần classifier LLM)
- Cache in-memory đủ (MCP process + browser session)
