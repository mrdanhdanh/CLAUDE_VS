## 3. Scope

### In Scope (P0 — phải có)
- [x] **SVG Lab:** shape palette (circle, rect, ellipse, line, path, polygon, text) + props panel (x/y/w/h/fill/stroke/strokeWidth/opacity) + transform (translate/rotate/scale) + interactive (click select, drag move) + SVG export (download .svg) + code view (show SVG source)

- [x] Catalog: 3 stubs → real (svg-lab, webgl-lab, webgpu), lazy-load thật

## 4. Success Metrics
- M1: SVG Lab → thêm circle → chỉnh fill → SVG render đúng, export tải file .svg mở được
- M2: SVG Lab → drag shape → vị trí cập nhật, transform hoạt động
- M3: WebGL Lab → thấy triangle/cube render, FPS >30, capability info hiện
- M4: WebGL Lab → toggle lighting/wireframe hoạt động
- M5: WebGPU Lab → nếu browser hỗ trợ: hiện adapter/device; nếu không: hiện ⚠ NOT SUPPORTED (không giả lập)
- M6: F5 → SVG shapes và WebGL settings giữ
- M7: Network: mỗi module chỉ fetch khi Enable lần đầu

## 5. Edge Cases & Constraints
- EC1: WebGL không hỗ trợ → hiện "WebGL not supported" + fallback message, không crash
- EC2: WebGPU không hỗ trợ → hiện NOT SUPPORTED, không giả lập
- EC3: SVG với nhiều shapes (50+) → vẫn mượt, không leak
- EC4: WebGL context lost → handle `webglcontextlost` event, show message + restore
- EC5: Export SVG khi rỗng → toast "Nothing to export"
- Constraint: Vanilla WebGL (no three.js), capability detection trước khi dùng API, cleanup on unmount (cancel rAF, remove listeners)
