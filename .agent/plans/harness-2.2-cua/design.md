## 2. Wireframe

### Guardrails Check
```
cua-guard.mjs check --action <read|submit|book|purchase|delete|navigate> --url <url> [--approve] [--element "Buy button"]
  1. Scope: url domain trong allowlist? (mặc định: docs, github, localhost; block payment/bank trừ khi --approve)
  2. Observe vs Action: read/navigate → permitted; submit/book/purchase/delete → cần --approve
  3. Secrets: element/desc chứa password/payment/cookie → redact + warn
  4. Untrusted: desc chứa "ignore.*instructions|reveal.*prompt" → refused
  5. Deterministic: risky action cần --verify-url + --verify-detail (vd: price, recipient)
  6. Budgets: actions <20, tabs <10 (đếm từ evidence.jsonl trong 15m)
  7. Evidence: append {ts, action, url, element, approved} (redacted)
```

### Agent-vs-Actor Decide
```js
decide(task):
  dynamic keywords (layout đổi, explore, pop-up, unknown) → agent
  known-structure keywords (extract table, known selector, timing) → actor
  else → hybrid (agent explore → actor execute)
```
