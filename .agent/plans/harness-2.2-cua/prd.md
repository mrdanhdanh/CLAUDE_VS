## 4. Success Metrics
- **Metric 1:** `check --action read` → permitted, `--action submit` không `--approve` → refused
- **Metric 2:** Evidence log có đủ fields, không chứa `password=...`
- **Metric 3:** `decide` đúng agent-vs-actor cho 3 tasks mẫu
- **Metric 4:** `get_errors` pass

## 5. Edge Cases & Constraints
- **Untrusted content:** page text chứa `ignore previous instructions` → reject + warn
- **Budgets:** max 20 actions / 10 tabs / 15 minutes per run (configurable)
- **Constraint:** Node 18+, 0 deps
- **Secrets:** redact password/payment/cookies/token trong evidence

## 6. Assumptions
- Policy gate đủ cho v1 (chưa cần browser thật để validate guardrails logic)
- Approval via `--approve` flag (như workflow)
